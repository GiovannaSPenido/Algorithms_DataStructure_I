# Algoritmos e Estruturas de Dados I (Java)

Exercícios e projeto final que fiz sozinha na disciplina de Algoritmos e Estruturas de Dados I,
no 1º semestre de Ciência da Computação (Centro Universitário Dom Helder).

## Que problema resolve
São mais de 170 programas em Java que praticam a base da programação: cada um resolve um
problema matemático ou de lógica pedido na disciplina. Serve como registro do meu aprendizado de Java.

## O que tem em cada pasta
- C03 a C07: entrada e saída com Scanner, condicionais e estruturas de repetição
- C08 a C11: vetores, matrizes e modularização com métodos
- C12 e C13: ArrayList e métodos numéricos
- C14/PROJETO_AEDI: projeto final, um menu que calcula cinco séries matemáticas, cada uma na sua classe
- C15: orientação a objetos (classes, construtores, getters e setters)

## Tecnologias
Java, IntelliJ IDEA

## Como rodar
Com o JDK instalado, na raiz do repositório:

    javac -d out C14/PROJETO_AEDI/src/C14EX01_GiovannaPenido.java C14/PROJETO_AEDI/src/SERIE_*.java
    java -cp out PRIMEIRO_SEMESTRE.C14.PROJETO_AEDI.src.C14EX01_GiovannaPenido

Os outros exercícios rodam do mesmo jeito: compile o arquivo e execute pelo nome do pacote
(PRIMEIRO_SEMESTRE.<pasta>.<classe>). Também dá para abrir a pasta no IntelliJ IDEA.
